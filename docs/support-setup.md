# Чат поддержки и хранение файлов

## Архитектура

- Студент общается с поддержкой прямо внутри Telegram Mini App.
- FastAPI подтверждает пользователя по подписанному Telegram `initData`.
- История сообщений и метаданные вложений хранятся в PostgreSQL.
- Сами файлы хранятся отдельно в S3-совместимом Object Storage. Браузер получает краткоживущие подписанные URL; bucket закрытый.
- WebSocket через Redis доставляет ответы оператора в открытый чат. Операторская панель находится на `/support-operator`.
- Лимит одного файла — 20 МБ. Разрешены изображения, PDF, DOC/DOCX, PPT/PPTX, XLS/XLSX, текстовые файлы и аудио. Голосовые записываются средствами браузера Mini App.

## Локальная разработка

Compose запускает MinIO и автоматически создаёт bucket `support-files`. Для удобства разработки там используются `minioadmin` credentials; перед любым внешним развёртыванием их нужно заменить.

1. Задать в `.env` секрет `SUPPORT_OPERATOR_TOKEN`.
2. Запустить или пересобрать проект: `docker compose up -d --build`.
3. Открыть Mini App и перейти в «Поддержка».
4. Для ответов команды открыть `/support-operator` и войти тем же секретом.
5. MinIO Console доступна локально на `http://localhost:9001`.

## Бесплатный старт и рост

Для разработки и локальных данных используется MinIO. В production рекомендуемый hosted-вариант — Cloudflare R2: стандартное хранилище включает 10 ГБ-месяц, миллион Class A запросов и 10 миллионов Class B запросов ежемесячно; исходящий трафик не тарифицируется. Сверх бесплатного лимита R2 тарифицируется по фактическому использованию.

Для переключения MinIO → R2 достаточно изменить `.env`:

```dotenv
S3_ENDPOINT_URL=https://<ACCOUNT_ID>.r2.cloudflarestorage.com
S3_BROWSER_ENDPOINT_URL=https://<ACCOUNT_ID>.r2.cloudflarestorage.com
S3_REGION=auto
S3_BUCKET=<bucket>
S3_ACCESS_KEY_ID=<R2_ACCESS_KEY_ID>
S3_SECRET_ACCESS_KEY=<R2_SECRET_ACCESS_KEY>
```

Клиентские ключи остаются только на API-сервере; WebApp получает только краткоживущие ссылки на чтение. Не делать bucket публичным. Не коммитить реальные ключи. Перед production заменить демонстрационные локальные MinIO credentials и настроить резервное копирование БД, retention и антивирусную проверку вложений.

Цены и месячные квоты могут меняться; сверяйте [актуальную страницу тарификации R2](https://developers.cloudflare.com/r2/pricing/) до включения платного usage.
