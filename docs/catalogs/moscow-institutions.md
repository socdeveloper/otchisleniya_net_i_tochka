# Каталог учебных заведений Москвы

На дату подготовки MVP в WebApp встроено начальное наполнение каталога: [institutions.ts](../../apps/webapp/src/data/institutions.ts). Поиск учитывает аббревиатуры и распространённые названия. Пользователь может предложить отсутствующее заведение.

## Источники для наполнения и последующей сверки

- [Портал открытых данных Минпросвещения России](https://opendata.edu.gov.ru/opendata/) — государственные наборы данных по образовательным организациям и уровням образования.
- [Открытые данные Минобрнауки России](https://minobrnauki.gov.ru/opendata/) — открытые данные по организациям высшего образования.
- [Портал открытых данных Москвы](https://data.mos.ru/) — региональные данные образовательных организаций, в том числе СПО.
- [Поступи Онлайн: вузы Москвы](https://msk.postupi.online/vuz/) — справочный перечень; агрегатор сообщает о 136 вузах, но включает собственную классификацию.
- [EduNetwork: колледжи Москвы](https://college.edunetwork.ru/77/) — справочный перечень; агрегатор сообщает о 173 колледжах в 2026 году.

## Точность и эксплуатация

Встроенный файл — стартовая выборка, а не заверенный полный реестр. Агрегаторы считают филиалы, колледжи при вузах и организации с разным статусом по собственной методике, поэтому цифры выше не суммируются и не означают, что все записи юридически относятся к городу Москве. Перед публичным запуском каталог нужно выгрузить/сверить с официальными государственными наборами, нормализовать дубли, хранить внешний идентификатор организации, тип (головная организация/филиал/колледж при вузе), регион, актуальность и источник. Справочник должен стать редактируемым через API/админ-панель; неподтверждённые заявки пользователей сначала попадают на модерацию.

Текущий интерфейс специально не блокирует регистрацию из-за неполного списка: поиск принимает название, а предложение отсутствующего учебного заведения продолжает онбординг.
